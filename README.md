# 坦克大战

基于 HTML5 Canvas 的经典坦克大战游戏，纯前端实现，打开即玩。

## 在线游玩

访问 [https://glfs1724.github.io/tank-battle/](https://glfs1724.github.io/tank-battle/) 即可开始游戏。

## 本地运行

1. 下载 `index.html` 文件
2. 用浏览器直接打开该文件即可

或者克隆仓库后打开：

```bash
git clone https://github.com/glfs1724/tank-battle.git
cd tank-battle
# 用浏览器打开 index.html
```

## 操作方式

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动坦克 |
| W A S D | 移动坦克（备选） |
| 空格 | 发射子弹 |
| P | 暂停 / 恢复 |

## 游戏规则

### 基本规则

- 消灭所有敌方坦克即可进入下一关，过关获得关卡数 × 50 的额外加分
- 共有 3 条命，被击中后损失一条命并在基地重生（1.5 秒无敌保护）
- 关卡递增，敌人数量逐渐增加（最多 8 个），地图随机变化
- 最高分自动保存至浏览器本地存储

### 基地防御

- 基地位于地图底部中央，**被敌人子弹击中则游戏立即结束**
- 玩家子弹碰到基地会消失（不会误伤己方基地）

### 道具系统

摧毁砖墙有概率掉落道具，拾取即可生效：

| 道具 | 颜色 | 效果 |
|------|------|------|
| ★ 星 | 黄色 | 升级坦克 — Lv.2 加速减装填，Lv.3 双发子弹 |
| 🛡 护盾 | 蓝色 | 5 秒无敌，坦克周围有蓝色光效 |
| 💣 炸弹 | 红色 | 立即消灭场上所有敌人 |
| ❄ 冻结 | 青色 | 冻结所有敌人 3 秒 |
| ♥ 生命 | 绿色 | 额外增加一条命 |

道具掉落约 15 秒后闪烁消失，需及时拾取。

### 敌人 AI

敌人分三种行为模式，身上有颜色标记：

| 模式 | 标记 | 概率 | 行为 |
|------|------|------|------|
| 追击型 | 红色 | 40% | 主动向玩家方向移动，速度更快 |
| 攻城型 | 橙色 | 30% | 向基地方向移动并射击，装填更快 |
| 随机型 | 灰色 | 30% | 随机方向移动 |

### 连杀系统

短时间内连续消灭敌人可触发 COMBO 加成，额外获得连杀分数。

## 地形说明

| 地形 | 颜色 | 特性 |
|------|------|------|
| 砖墙 | 棕色 | 可被子弹摧毁，可能掉落道具 |
| 钢铁 | 灰色 | 不可摧毁，阻挡子弹 |
| 水池 | 蓝色 | 坦克和子弹均不可通过 |
| 树林 | 绿色 | 遮挡视野，子弹和坦克可穿过 |

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- Web Audio API（音效）
