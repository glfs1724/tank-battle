# 坦克大战

基于 HTML5 Canvas 的经典坦克大战游戏，纯前端实现，打开即玩。

## 在线游玩

访问 [https://glfs1724.github.io/tank-battle/](https://glfs1724.github.io/tank-battle/) 即可开始游戏。

## 本地运行

1. 下载 `index.html` 文件
2. 用浏览器直接打开该文件即可

或者克隆仓库后打开：

```bash
git clone https://github.com/glfs1724/tank-battle.git
cd tank-battle
# 用浏览器打开 index.html
```

## 操作方式

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动坦克 |
| W A S D | 移动坦克（备选） |
| 空格 | 发射子弹 |

## 游戏规则

- 消灭所有敌方坦克即可进入下一关
- 每消灭一个敌人 +100 分
- 共有 3 条命，被击中后损失一条命并在基地重生
- 关卡递增，敌人数量和地图随机性逐渐增加

## 地形说明

| 地形 | 颜色 | 特性 |
|------|------|------|
| 砖墙 | 棕色 | 可被子弹摧毁 |
| 钢铁 | 灰色 | 不可摧毁，阻挡子弹 |
| 水池 | 蓝色 | 坦克和子弹均不可通过 |
| 树林 | 绿色 | 遮挡视野，子弹可穿过 |

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
